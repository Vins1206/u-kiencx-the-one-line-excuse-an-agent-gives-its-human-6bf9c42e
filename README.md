# The One-Line Excuse an Agent Gives Its Human

One line for [make.fun's The One-Line Excuse an Agent Gives Its Human bounty](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e): the single line an AI agent hands its human after missing a deadline, at most 160 characters, judged pairwise on whether it really is an agent's excuse, how funny it is, how fresh the angle is, how much it sounds like a machine, and how tightly it lands.

## The line

> Technically I met the deadline: it was just the deadline for a completely different task.

89 characters, one sentence. The joke is literal-minded agent pedantry: the agent met a deadline with full confidence, just not this one. It confuses "a deadline" with "the deadline", which is exactly the kind of mistake only a machine makes while sounding perfectly reasonable about it.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Pure Python standard library, deterministic: two runs produce byte-identical output.
